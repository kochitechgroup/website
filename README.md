# kochitechgroup.dev

Website for Kochi Tech Group. Built with [Astro](https://astro.build) and deployed on Cloudflare Pages.

```sh
bun install     # also installs the git hooks
bun run dev     # local dev server
bun run check   # constraint checks
bun test        # unit tests for the checks and hooks
bun run build   # output in dist/
```

Contributor and agent guidance is in [AGENTS.md](AGENTS.md).
